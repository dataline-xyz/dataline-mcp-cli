# Security Policy

## Supported Versions

Security fixes are applied to the latest released minor version until a formal support matrix is
published.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting
for this repository. If private reporting is not yet enabled, contact a repository maintainer
privately before sharing details.

Include the affected version, access mode, reproduction steps, and expected impact. Never include
live access tokens, API keys, wallet private keys, seed phrases, or funded payment payloads in a
report.
